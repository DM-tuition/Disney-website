# Wisney ✨ — Where Shopping Becomes Magic

A demo Disney-store concept built for a **Lancaster University marketing challenge**:
*"How can Disney improve its online shopping experience?"* — answered through the lens of
the **SAVE framework** (Solution · Access · Value · Education).

> Wisney is a fictional, unaffiliated demo built for a student competition.

## ▶️ How to run it (no install needed)

Just open `index.html` in any browser. That's it. Everything is self-contained
(HTML + CSS + vanilla JS), so it works offline — perfect for presenting on the day.

```
open index.html        # macOS
# or double-click the file, or:
python3 -m http.server  # then visit http://localhost:8000
```

## ✨ The features (and the marketing behind them)

| Feature | What it does | SAVE pillar |
|---|---|---|
| **Choose Your Magic** onboarding | Personalises the store to a world (Toy Story, Frozen…) & your name | Solution |
| **Magic Gift Finder** quiz | 3 questions → a perfect recommendation | Solution |
| **AR "Try at Home"** | Drop a character onto your shelf before buying | Solution / Access |
| **Slide-out cart + free-shipping nudge** | Progress bar to €50 reduces drop-off | Access |
| **Tinker Bell chatbot** | Always-on help (orders, gifts, points) | Access |
| **Magic Rewards tiers** | Pixie Points → Dreamer → Royalty, with perks | Value |
| **Spin the Pixie Wheel** | Daily gamified reward | Value |
| **Storytelling product cards** | Every item has a mini-story, not just specs | Education |
| **Live social-proof toasts** | "Emma just bought Buzz" builds trust & urgency | Education |
| **Midnight Magic Drop countdown** | Scarcity / urgency | Education |
| **Magic List newsletter** | Captures the relationship + 10% welcome spell | Education |

Plus all the over-the-top delight: pixie-dust cursor trail, confetti bursts,
a day/night-at-the-park theme toggle, animated castle hero, fly-to-cart animation,
and reveal-on-scroll throughout.

## 🗂️ Files

- `index.html` — structure & content
- `styles.css` — all styling, animations, day/night theming
- `script.js` — cart, wishlist, points/tiers, quiz, AR, wheel, chat, confetti

## 🎤 Presenting tip

Open with the **"Choose Your Magic"** popup (it appears on load), then walk the judges
through the **Gift Finder → AR → Rewards → Spin** journey. Finish on the
**"The Strategy"** section, which maps every feature back to SAVE.
